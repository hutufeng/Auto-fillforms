# 身份证智能录入与扫描助手 · 使用指南

---

## 📖 软件概述
**身份证智能录入与扫描助手** 是一款专注于二代身份证全流程自动化处理的纯绿色免安装桌面工具。软件集成离线 OCR 文本结构化提取、卡面微倾斜纠偏、国标圆角切片、免冠头像自动提取、A4 规范扫描件排版及 Word/Excel 模板智能套打等功能。

- **运行模式**：绿色单文件，解压即用，无需配置 Python 环境或安装第三方运行库；
- **数据隐私**：所有图像处理与 OCR 识别均在用户本地离线完成，无任何公网数据外发。

---

## 一、首次运行与授权激活

1. 双击运行当前目录下的 **`身份证智能录入与扫描助手.exe`**；
2. 首次启动软件会自动弹出授权验证对话框，点击界面上的 **【一键复制机器码】**；
3. 将机器码发送给授权管理员，获取 16 位专属卡密；
4. 将卡密粘贴到输入框中，点击 **【立即联网验证激活】**（仅激活时需连接网络验证 1 秒）；
5. 验证成功后系统将自动生成离线授权文件，后续启动支持永久脱机离线使用。

---

## 二、单张识别与功能操作

### 1. 导入证件图片
- **常规模式**：分别点击左侧面板的【选择正面】与【选择反面】导入图片；
- **单图双面模式**：若一张照片内同时拍有正反两面，直接在【正面/双面图】处导入该图片即可。

### 2. 执行识别提取
- **【⚡ 快速提取 (纯 OCR)】**：1 秒内快速提取文字信息并填入右侧表单；
- **【📸 完整识别 (含切片)】**：提取文字的同时，自动完成角度纠偏、国标尺寸规范化（`1011 × 638` 像素 @ 300DPI）、平滑抗锯齿圆角裁切，并精准切取免冠证件照头像。

### 3. 头像与卡片使用
- **一键复制头像**：识别完成后，点击【复制头像】，即可直接在微信聊天框、Word、WPS 或其他办公软件中按 `Ctrl + V` 粘贴使用；
- **另存头像**：点击【另存头像】可将二代证免冠证件照单独保存为高清 JPG 文件。

### 4. 导出 A4 规范扫描件
1. 点击界面下方的 **【🖨️ 导出此人 A4 扫描件】**；
2. **质感模式**：可按需选择【彩色高清】（还原真实证件色彩）或【黑白复印机】质感；
3. **防盗用水印**：勾选【防盗用水印】可自定义文字（如：“*仅供办理入职使用 他用无效*”），系统将在卡面上生成高保真倾斜半透明水印；
4. **格式选择**：支持一键导出为标准 300DPI 印刷级 PDF 或单张 JPG 图像。

## 三、批量处理与自动配对

切换至软件顶部的 **【批量表格生成】** 标签页：

### 1. 批量导入图片
点击 **【选择图片文件夹】** 导入包含多张身份证照片的文件夹，系统将自动根据文件名分析归属人并完成正反配对。

**推荐的文件命名规则**（配对率最高）：
- 同人加序号：`张三1.jpg`、`张三2.jpg`
- 括号编号：`李四(1).jpg`、`李四(2).jpg`
- 正反标识：`王五_正.jpg`、`王五_反.jpg`
- 单图双面：`赵六.jpg`（一人一张，单图内含正反两面）

### 2. 列表管理与多选移除
- **快捷多选**：支持鼠标配合 `Ctrl`（单点多选）或 `Shift`（连续多选）进行快速选择；
- **移除误选项**：选中列表中的项目后，点击右侧的 **【移除选中项】**，即可随时剔除误传或无关图片。

### 3. 开始处理与成果导出
点击 **【开始批量识别】**，进度条实时更新。识别完成后可选择：
- **【导出 Excel 表格】**：一键将所有人员的数据汇聚导出为标准 Excel 台账（包含姓名、性别、民族、出生日期、年龄、身份证号、住址、签发机关、有效期限）；
- **【批量导出 A4 扫描件】**：可选择为每位人员生成专属独立扫描件，或合并导出为单份全员多页汇总 PDF。

## 四、Word / Excel 模板智能套打

如果您单位有固定格式的《员工入职登记表》、《学员报名表》或《申报花名册》，可使用模板套打功能实现自动填表。

### 1. 模板制作占位符说明
在 Word（`.docx`）或 Excel（`.xlsx`）模板中放置以下占位符：

**文字字段占位符**：
```jinja2
{{姓名}}  {{性别}}  {{民族}}  {{出生日期}}  {{年龄}}
{{身份证号码}}  {{住址}}  {{签发机关}}  {{有效期限}}
```

**图片字段占位符（仅 Word .docx 支持）**：
- `{{avatar}}`：自动插入免冠二代证证件照头像；
- `{{card_front}}`：自动插入正面标准切片卡片；
- `{{card_back}}`：自动插入反面标准切片卡片。

### 2. 执行套打导出
1. 点击软件界面的 **【选择 Word/Excel 模板】** 载入自定义模板；
2. 点击 **【填充并导出】**，系统将自动为每位人员生成一份排版完整、图文并茂的最终成品文档。

## 五、使用注意事项

1. **拍照环境**：拍摄身份证时尽量平放拍摄，光线均匀，避免强烈反光遮挡关键字符或人像；
2. **杀毒软件提示**：本软件采用 PyInstaller 打包为单文件便携版，未购买昂贵的企业数字签名证书，个别杀毒软件若出现风险拦截提示，纯属误报，添加信任或允许运行即可；
3. **更换设备使用**：若需更换电脑运行，点击软件右上角【商业授权】菜单，选择【换机解绑】后即可在另一台电脑上重新激活绑定。
