1. 解压下载的压缩包到电脑任意文件夹（建议不要放在含有特殊符号的深层路径）。
2. 双击运行【身份证OCR.exe】。

二、单张识别与 A4 扫描件导出
----------------------------------------------------------------------
1. 导入图片：
   - 点击左侧【选择正面】与【选择反面】分别选择两张图片；
   - 或者如果一张图片里同时拍了正反两面，直接在正面处导入该图片即可。
2. 开始识别：
   - 点击【⚡ 快速提取 (纯 OCR)】：1 秒内快速提取文字表格；
   - 点击【📸 完整识别 (含切片)】：自动校正倾斜、裁剪国标圆角卡面并提取高清免冠头像。

4. 导出 A4 标准扫描件：
   - 点击【🖨️ 导出此人 A4 扫描件】；
   - 可按需选择【彩色扫描】或【黑白复印】；

   - 点击立即生成 300DPI 标准印刷级 PDF 或 JPG！

三、批量自动配对与全员汇总导出
----------------------------------------------------------------------
1. 切换到【批量表格生成】标签页。
2. 点击【选择图片文件夹】选择包含身份证照片的文件夹（或直接拖拽图片到列表）。
3. 文件名命名小建议（自动配对最精准）：
   - 张三1.jpg、张三2.jpg
   - 李四(1).jpg、李四(2).jpg
   - 王五_正.jpg、王五_反.jpg
   - 若一人一张合图，直接命名为：赵六.jpg
4. 列表支持按住 Ctrl 或 Shift 鼠标多选，点击【移除选中项】可随时清除误加的图片。
5. 点击【开始批量识别】，完成后可点击：
   - 【导出 Excel 表格】：一键生成包含所有人信息汇总的标准 Excel 台账；

如果您有固定的入职登记表、花名册或申报表需要自动填入：
1. 在您的 Word (.docx) 模板中使用以下占位符：
   文字标签：{{姓名}}  {{性别}}  {{民族}}  {{出生日期}}  {{年龄}}
             {{身份证号码}}  {{住址}}  {{签发机关}}  {{有效期限}}
